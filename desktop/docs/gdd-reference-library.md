## 二、从这十几份里，看出的「为什么」

1. **写法由"读者"决定**：给发行商=短(8 页)、给程序=规格/状态机、给贡献者=带理由的规范、给玩家=试玩版。**没有统一文体，只有统一目标：让某个人能干活。**
2. **数值 = 表**：中外一致——国内数值案是 Excel，恩皮西是树状多表；**没人用散文写数值**。
3. **早期 = 清单**：Cryptic 的功能表、立项报告——项目越早，文档越像"排期/清单"。
4. **大型 = wiki**：0 A.D.、Cataclysm-DDA——一旦长期维护，单文件必然拆成知识库。
5. **形式不重要，目的重要**：中文行业一句实话——**"实际工作中不局限形式，word / excel / ppt / 几张原型图都可能"**，关键是**解决沟通问题**。
6. **2026 的新变量**：文档开始为 **AI 可读**而写（Markdown + Git + 分章），这是新一层"读者"。
