### 第二十章·数据埋点与指标 · 指标体系

> 为什么必须写清：指标口径（留存/漏斗/付费）

| 指标名 | 定义 | 统计口径 | 目标值 |
| --- | --- | --- | --- |
| DAU | 日活跃用户数 | 自然日去重，UTC+8 0 点切分 | 20 万 |
| 付费率 | 当日付费人数 / 当日活跃 | 自然日，去重 | 6% |
| ARPU | 日均收入 / 日均活跃 | 自然日 | ¥8 |
| 剧情通关率 | 通关第一章人数 / 进入第一章人数 | 7 日窗口 | ≥70% |
| D30 留存 | 注册 30 日后仍活跃比例 | cohort 去重 | ≥18% |
| 抽卡 ARPU | 卡池收入 / 抽卡人数 | 卡池周期 | ¥45 |
| 论剑参与率 | 赛季参与论剑人数 / 活跃 | 赛季 | ≥35% |
| 日均时长 | 人均在线时长 | 自然日 | 42 min |
