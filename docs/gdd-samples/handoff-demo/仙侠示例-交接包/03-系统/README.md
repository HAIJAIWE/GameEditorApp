## 这一卷做完，游戏能做什么

装备/成长/经济三套系统能独立跑通，资源闭环可复算，词条与强化有明确规则。

**规模**：1 套经济闭环 + 1 条成长线 + 1 套装备规则

**前置**：01 核心玩法卷（第一条可玩链路）

## 本卷验收（整卷做完逐条打勾）

- [ ] 每个启用的系统都有配置表且能被代码读取
- [ ] 新手前 10 分钟的收支与账本一致（误差在容差内）
- [ ] 装备/词条的数值来源可追到参数表

## 本卷明确不做

- 付费与商业化
- 赛季重置
- 跨服交易
