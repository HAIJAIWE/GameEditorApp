# 策划书（Ceshu）使用指南

> 📌 面向最终用户：如何用现役 TypeScript 版的工业级 GDD 系统创建、编辑、导出游戏策划书。
> 适用：菜单栏 → 策划书首页（卡片视图）→ 编辑器。

## 一、概述

### 1.1 什么是策划书（GDD）系统
墨白可视化编辑的核心模块，提供结构化的游戏策划书编辑环境。它把策划过程拆解为 **16 个编号章节 + 文档信息段（meta）**，按 **5 个分区** 组织，覆盖从产品定义到制作发行的完整链路，并配套评分、校验、模板、AI 辅助、版本管理。

**核心特征：**
- **16 章标准结构（5 区）**：产品定义 / 游戏系统 / 表现设计 / 技术方案 / 制作与发行
- **13 个游戏系统配置**：战斗 / 角色 / 技能 / 装备 / 物品 / 任务 / 社交 / 经济 / 成长 / 外观 / 关卡 / 抽卡 / 竞技（含硬依赖）
- **两种档位**：标准版（lite，核心 9 章）/ 工业级（full，16 章）
- **6 种导出格式**：Markdown / HTML / Word(docx) / PowerPoint(pptx) / PDF / Excel(xlsx)
- **AI 深度嵌入**：字段填充 / 整章生成 / 一键完整生成 / 智能审阅 / AI 数据生成
- **版本管理**：派生版本 / 版本对比 / 时间线 / 变更日志
- **完备性检查**：生产就绪检查清单

### 1.2 入口
启动后默认进入**策划书首页**（卡片视图），展示当前库下所有策划书。点卡片「打开」进入编辑器；点「+ 新建策划书」开始创建。顶部菜单栏的「当前库」可切换/新建游戏库。

## 二、快速开始：创建第一本策划书

### 2.1 新建：选档位
点「新建策划书」→ 选择档位（标准版 lite / 工业级 full）与（可选）混合玩法预设 → 填写文档信息（游戏名、类型、一句话定位、标签、文档状态、保密级别）。`meta` 不占章号，是封面信息。

### 2.2 编辑你的第一章
进入编辑器后，左侧是分区/章节导航（按 5 区分组，章号自动生成「第N章·名称」）。点章节进入表单（schema 驱动）：文本框/多行/数字/下拉/多选/开关/列表/结构化行表/JSON。必填字段在进度计算中计入。

### 2.3 启用游戏系统
在「游戏系统设计」章（属二、游戏系统区）勾选要用的系统；启用时会校验硬依赖（如启用「战斗」要求已启用「角色」「技能」），不满足会提示补启用。确认系统后写入 `meta.system_confirmed`，并自动把系统映射为游戏数据类型，进入下一步「设计游戏数据」。

### 2.4 校验与导出
- 点工具栏「校验」看一致性错误（必填/系统依赖）。
- 点「评分」看三维评分与等级。
- 点「导出」选 6 种格式之一，主进程代开保存对话框落盘。

## 三、章节结构（16 章 + meta + 5 区）

| 区 | 章 | 说明 |
|---|---|---|
| 文档信息（meta，不编号） | 文档信息 | 游戏名/类型/定位/标签/状态/保密级别/档位 |
| 一、产品定义 | 产品愿景 | 设计愿景、差异化 |
| | 世界观与角色 | 世界架构、主线、主角、主要 NPC（原世界观+角色合并） |
| | 核心玩法 | 核心循环、玩法模式 |
| 二、游戏系统 | 游戏系统设计 | 13 系统开关与依赖 |
| | 战斗系统设计 | 战斗模式、伤害公式 |
| | 经济系统设计 | 货币、产出/消耗 |
| | 数值设计 | 核心公式、平衡原则 |
| 三、表现设计 | 美术设计 | 美术风格、色彩体系 |
| | 音频设计 | 音乐风格、音效数量 |
| 四、技术方案 | 技术规格 | 引擎等 |
| 五、制作与发行 | 资源规划 | 预算 |
| | MVP 规划 | 范围、时间线 |
| | 风险控制 | 风险矩阵、预案 |
| | 市场分析 | 目标市场、竞品 |
| | 商业化设计 | 付费模型、档位 |
| | 可访问性与本地化 | 语言、无障碍特性 |

> 档位差异：`lite` 仅渲染核心 9 章（产品定义 3 章 + 游戏系统前 4 章 + 表现设计 2 章）；`full` 渲染全部 16 章。

## 四、核心功能使用

### 4.1 章节编辑与表单
schema 驱动表单；文本字段旁若有「AI」圆钮，可点它用 AI 单字段填充（值回填表单、需手动保存）。

### 4.2 游戏系统配置
「游戏系统设计」章是系统开关中枢；`SystemsEditor` 支持就地编辑各系统 config 字段；`SystemConfirmPanel` 在 AI 生成后自动弹出确认（确认后不再自动弹）。

### 4.3 校验与一键修复
`validate` 给出必填/依赖错误；`autoFill` 自动补齐空必填（不调 LLM）。

### 4.4 评分系统
三维（结构/质量/市场）0–100，S/A/B/C/D 五级；`score` 返回各章明细与改进建议（`AiFullGeneratePanel` 也会展示确定性评分门结果）。

### 4.5 模板库与自定义模板
可把当前章节存为模板（`ceshu:templates:save`），后续套用到同章；自定义模板存 `<库>/custom_templates/<category>.json`，支持导入/导出。

### 4.6 AI 辅助
- **字段填充**：单字段定向生成（不落盘、不审批）。
- **整章生成**：可「仅填空字段」；大范围云端调用需确认 + 预算闸。
- **一键完整生成**：整篇草稿，过确定性评分门 + 可选 LLM judge。
- **智能审阅**：整篇审阅 + 改进建议。
- **AI 数据生成**：依策划书数值/系统生成候选数据 → 预览勾选 → 导入数据表。

### 4.7 版本管理
`derive` 派生新版本（保留链）；`versions` + `changelog` 查看；`diff` + 报告导出做两版对比；`VersionTimelinePanel` 看时间线。

### 4.8 完备性检查清单
`checklist` 生产就绪检查；所有 required 项通过才算制作就绪。

### 4.9 字数统计
`wordStats` 分章节字数。

### 4.10 字段依赖关系图
`fieldDeps` 跨章节字段依赖（如战斗公式依赖数值章字段），用于定位遗漏。

### 4.11 章节笔记
`notes` 给任意章节加笔记（作者/内容），存 `<库>/ceshu_notes/<id>.json`。

## 五、导出格式
markdown / html / docx / pptx / pdf / excel 六选一；分区标题与章号自动生成。PDF 依赖系统可用的文档渲染链。

## 六、混合玩法预设
`ceshuPresets` 提供预设（如仙侠 RPG 等），`applyPreset` 一键套用推荐系统与章节默认值；预设可在「游戏系统设计」章按需增删自定义系统。

## 七、键盘快捷键
- `Ctrl+Z` 撤销 / `Ctrl+Y`（或 `Ctrl+Shift+Z`）重做（输入框内不拦截，保留本地撤销）。
- `Esc` 关闭当前浮层。

## 八、FAQ
- **Q1：旧 v4 数据能打开吗？** 能。`ceshuMigration.ts` 在加载时归一旧版（v4→v5 结构），无需手工迁移。
- **Q2：评分 D 怎么改善？** 看 `score` 返回的 `suggestions` 与按章明细，补齐必填与质量短板。
- **Q3：AI 生成质量不行？** 检查 LLM 档位（本地 Ollama 小模型 vs 云端 DeepSeek），或缩小生成范围（整章→字段）。
- **Q4：版本怎么用？** 主策划上点「派生」建分支；对比用 `diff`。
- **Q5：导出 PDF 失败？** 看主进程日志（`<userData>/logs`）；其余 5 种格式不依赖额外渲染链。
- **Q6：自定义模板在哪？** `<库>/custom_templates/<category>.json`，可经模板面板导入/导出。
- **Q7：预设能自定义吗？** 可以：在「游戏系统设计」章手动增删系统并保存，不锁死预设。
- **Q8：多库怎么切换？** 顶部菜单栏「当前库」下拉切换/新建；切换会整页重载并广播 `library:changed`。
