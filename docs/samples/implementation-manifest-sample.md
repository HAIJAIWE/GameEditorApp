# 实现契约（构建清单）— 云海剑歌

> 游戏类型：RPG｜档位：full

## 一、构建顺序（垂直切片优先，非文档顺序）
1. **数据层：实体与字段** — 按 3 个已启用系统建实体与字段
2. **状态机骨架** — 按 6 条转移实现状态机（含异常路径）
3. **核心循环跑通一局** — 按 5 步核心循环做出最小可玩闭环；内容：4 个核心特性 / 3 个首关
4. **数值约束落地** — 实现时守住 6 条数值约束（公式/平衡/断言）
5. **验收** — 按 5 条验收标准判定完成

## 二、核心循环
探索云海 → 遇敌/秘境 → 战斗 → 获得灵材与功法 → 打坐突破 → 解锁新区域 → 循环
- 探索地图与秘境
- 遭遇战斗
- 获取灵材/功法
- 打坐突破境界
- 解锁新区域

## 四、系统模块（数据实体）
### 战斗（battle）
- turn_mode: 半即时（行动条）
- battle_duration: 30-90 秒/场
- damage_formula: 伤害 = 攻击 × 技能倍率 − 防御 × 0.5
### 角色（character）
- max_level: 60
- attribute_system: 体魄/灵力/身法/悟性
### 经济（economy）
- currency_types: 灵石（软）/ 仙玉（硬）
- sink_mechanisms: 突破消耗灵石/装备强化

## 六、数值约束
- 【数值公式·要点】伤害 = 攻击 × 技能倍率 − 防御 × 0.5
- 【数值公式·要点】气血上限 = 40 + 体魄×6 + 境界×10
- 【平衡原则】战力随境界线性增长
- 【平衡原则】突破成功率 35%–95% 随悟性递增
- 【平衡原则】灵石产出略低于突破消耗，驱动持续探索
- 【数值断言】同境界满血单挑|30秒内可击杀普通妖|单局 ≤ 90s|±20%|通过

## 七、验收标准
- [ ] 试玩 30 分钟内跑通核心循环且无阻断 bug（来源：MVP 里程碑：α 垂直切片）
- [ ] 5 名测试者各完成 1 次完整突破（来源：MVP 里程碑：β 内容填充）
- [ ] 首日崩溃率 < 1%，次日留存 ≥ 35%（来源：MVP 里程碑：γ 上线版）
- [ ] 核心循环可完整跑通（来源：QA 验收准则）
- [ ] 无阻断性 bug（来源：QA 验收准则）

## 八、表现基线（通用最小手感，非文档派生）
> 通用最小表现基线（非文档派生，作为可玩性下限；成品需美术/音频专项打磨）
- 受击：目标闪红 + 轻微击退，给出「打中了」的即时反馈
- 命中：60–100ms 顿帧 + 伤害飘字，避免无声无息掉血
- 技能：有施法前摇与冷却，不瞬发连按
- 胜负：结算面板明确胜/负与获得，可一键再战
- 操作：首局 3 分钟内可发现全部核心操作，无需读文档
