# 实现契约（构建清单）— 云海剑歌

> 游戏类型：RPG｜档位：full

## 一、构建顺序（垂直切片优先，非文档顺序）
1. **数据层：实体与字段** — 按 3 个已启用系统建实体与字段
2. **状态机骨架** — 按 6 条转移实现状态机（含异常路径）
3. **核心循环跑通一局** — 按 5 步核心循环做出最小可玩闭环
4. **验收** — 按 3 条验收标准判定完成

## 二、核心循环
探索云海 → 遇敌/秘境 → 战斗 → 获得灵材与功法 → 打坐突破 → 解锁新区域 → 循环
- 探索地图与秘境
- 遭遇战斗
- 获取灵材/功法
- 打坐突破境界
- 解锁新区域

## 三、状态转移表
| 状态 | 触发事件 | 结算效果 | 新状态 |
|---|---|---|---|
| 主菜单 | 点击「开始修行」 | 加载存档，进入新手村 | 对局中 |
| 对局中 | 交互物触发战斗 | 切入战斗场景 | 战斗中 |
| 战斗中 | 敌方全灭 | 结算掉落，返回地图 | 对局中 |
| 战斗中 | 我方气血归零 | 结算失败，弹出接关 | 失败 |
| 对局中 | 打开打坐面板 | 暂停移动，进入突破判定 | 突破中 |
| 突破中 | 成功率判定通过 | 境界+1，刷新属性 | 对局中 |

## 四、系统模块（数据实体）
### 战斗（battle）
- turn_mode: 半即时（行动条）
- battle_duration: 30-90 秒/场
- damage_formula: 伤害 = 攻击 × 技能倍率 − 防御 × 0.5
### 角色（character）
- max_level: 60
- attribute_system: 体魄/灵力/身法/悟性
### 经济（economy）
- currency_types: 灵石（软）/ 仙玉（硬）
- sink_mechanisms: 突破消耗灵石/装备强化

## 五、验收标准
- [ ] 试玩 30 分钟内跑通核心循环且无阻断 bug（来源：MVP 里程碑：α 垂直切片）
- [ ] 5 名测试者各完成 1 次完整突破（来源：MVP 里程碑：β 内容填充）
- [ ] 首日崩溃率 < 1%，次日留存 ≥ 35%（来源：MVP 里程碑：γ 上线版）
